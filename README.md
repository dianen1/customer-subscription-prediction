# Predicting Customer Subscription Status Using Behavioral and Promotional Factors

## Overview
This project predicts customer subscription status using behavioral and promotional variables through machine learning classification models.

The study compares Logistic Regression, Support Vector Machine (SVM), and Random Forest algorithms to determine the most effective predictive model.

## Objectives
- Predict customer subscription status
- Identify factors influencing subscriptions
- Compare machine learning classification models

## Dataset
The dataset contains 1,500 customer records from a Philippine coffee business context.

### Selected Features
- Review Rating
- Previous Purchases
- Product Category
- Discount Applied
- Promo Code Usage

## Methodology
The project follows the SEMMA framework:
1. Sample
2. Explore
3. Modify
4. Model
5. Assess

## Machine Learning Models
- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest

## Evaluation Metrics
- Accuracy
- F1-Score
- Cohen’s Kappa

## Results
- Random Forest achieved the highest accuracy (84.4%)
- Discounts and promo codes were the strongest predictors
- Product category had minimal influence on subscriptions
